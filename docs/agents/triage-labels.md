# 分诊标签

工程技能使用五个标准分诊角色；下表映射到本仓库实际使用的标签。

| 标准角色 | 跟踪器标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 必须由人工实施 |
| `wontfix` | `wontfix` | 不处理 |

当技能提及某个标准角色时，使用表中对应的跟踪器标签。后续接入 GitHub 时可将右侧一列改为仓库已有标签。
