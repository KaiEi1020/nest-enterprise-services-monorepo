# 05 — bsc-marketing 奖品管理

**What to build:** 管理员可通过 `bsc-marketing` 的 gRPC 领域动作创建、分页查询、查看详情、更新、删除奖品；奖品具有全局固定兑换积分与全局可用库存，可被多个营销活动复用，为活动奖品配置提供可复用的权益或实物定义。

**Blocked by:** 01 — Nx Monorepo 基线

**Status:** ready-for-agent

- [ ] 管理员可对奖品执行完整 CRUD gRPC 动作
- [ ] 奖品包含名称、描述、图片、类型、全局固定兑换积分、全局可用库存、状态
- [ ] 更新全局可用库存不得低于当前已分配给各活动的占用量
- [ ] 删除为软删除，已删除奖品不出现在默认列表
- [ ] BSC gRPC 接缝测试覆盖 CRUD 与库存约束
