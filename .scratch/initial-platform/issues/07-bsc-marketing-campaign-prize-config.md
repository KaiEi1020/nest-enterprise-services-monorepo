# 07 — bsc-marketing 活动奖品配置与活动库存

**What to build:** 管理员可将奖品加入营销活动并分配活动库存，可调整或移除活动奖品配置；活动库存从奖品全局可用库存中分配并占用，调整时不得低于已发放数量，新增分配必须有全局可用库存支撑，为兑换提供可发放能力。

**Blocked by:** 06 — bsc-marketing 营销活动管理, 05 — bsc-marketing 奖品管理

**Status:** ready-for-agent

- [ ] 管理员可将奖品加入营销活动并分配活动库存
- [ ] 管理员可调整活动库存；调整后不得低于已发放数量
- [ ] 新增活动库存分配校验全局可用库存，防止超额分配
- [ ] 管理员可移除活动奖品配置并释放其未发放库存
- [ ] BSC gRPC 接缝测试覆盖分配、调整、移除与库存不变量
