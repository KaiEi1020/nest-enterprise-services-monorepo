# 03 — bsc-user 用户管理

**What to build:** 管理员可通过 `bsc-user` 的 gRPC 领域动作创建用户、分页查询用户、查看用户详情、更新用户资料与状态、删除用户，使管理后台能够维护可登录身份。

**Blocked by:** 02 — bsc-user 身份与登录

**Status:** ready-for-agent

- [ ] 管理员可创建用户，用户与认证实体在同一事务中持久化
- [ ] 重复邮箱或用户名返回明确冲突错误
- [ ] 管理员可分页查询用户、查看详情、更新资料与状态、删除用户
- [ ] 删除为软删除，已删除用户不出现在默认列表
- [ ] BSC gRPC 接缝测试覆盖各动作与冲突场景
