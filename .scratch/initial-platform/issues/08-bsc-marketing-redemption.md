# 08 — bsc-marketing 兑换与兑换记录

**What to build:** 学生可用积分兑换活动中奖品的一个单位：`bsc-marketing` 预占活动库存后同步 gRPC 调用 `bsc-user.DeductPoints`，成功则确认库存扣减并生成待发放兑换记录，失败则释放预占库存并返回失败；运营人员可将待发放兑换记录标记为已发放或取消，取消时退还积分并释放活动库存。

**Blocked by:** 07 — bsc-marketing 活动奖品配置与活动库存, 04 — bsc-user 积分余额

**Status:** ready-for-agent

- [ ] 学生兑换一个单位时，系统预占活动库存并同步扣减积分
- [ ] 扣减成功生成待发放兑换记录并确认库存扣减；扣减失败释放预占库存且不产生记录
- [ ] 运营人员可分页查询待发放兑换记录
- [ ] 运营人员可将待发放标记为已发放；已发放不可再取消
- [ ] 运营人员可取消待发放；取消退还积分并释放活动库存
- [ ] BSC gRPC 接缝测试覆盖兑换成功、扣减失败、标记发放与取消退还的一致性
